# Pixeldrain Downloader

Upload a `.dlc` file, it decrypts the container, converts the links, and
downloads everything in parallel — then gives you downloadable files
right in the page, phone-friendly out of the box.

See `HOW_TO_DEPLOY.md` for the step-by-step, no-terminal way to put this
on Hugging Face Spaces (free Gradio tier).
